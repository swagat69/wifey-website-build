# Wifey Website Build

DESIGN AND BUILD A COMPLETE, PRODUCTION-QUALITY WEBSITE FOR:

HIRE A WIFEY
Hervey Bay, Queensland
Tagline: WE TAKE CARE OF HOME.

IMPORTANT:
This website must NOT look AI-generated, generic, corporate, overly polished, or like a standard cleaning-company template.

It should feel like a real, established local Australian service business with a distinctive personality.

The website should communicate one central idea:

HIRE A WIFEY IS NOT JUST SELLING CLEANING.

THE PRODUCT IS TIME.

The cleaning, laundry, ironing, dishes, bed making, organisation, meal preparation and household assistance are the practical services used to give customers something much more valuable:

LESS TO DO.
LESS HOUSEWORK WAITING FOR THEM.
MORE TIME BACK.

The emotional outcome should be visible throughout the website:

"Come home with less to do."

==================================================
1. BRAND DIRECTION
==================================================

Use the supplied Hire A Wifey logo as the primary brand reference.

Do not redraw, reinterpret, distort, auto-generate or replace the logo.

Use the supplied logo accurately and preserve its proportions.

The supplied brand uses:
- Black
- Strong feminine pink
- White
- Soft blush/pale pink as a supporting background colour

The logo has a playful but premium editorial quality, combining bold typography with the house/wife visual idea.

The supplied uniform imagery establishes an important visual language:
- Black garments
- Strong pink piping
- Pink collar detailing
- Pink/black branding
- Professional but feminine presentation

Use this as inspiration for the website's visual identity.

Do NOT turn the website into:
- a pink-heavy beauty website
- a stereotypically feminine lifestyle website
- a generic domestic cleaning website
- a childish "cute" brand
- a luxury hotel website
- a SaaS dashboard
- a startup landing page
- an AI-generated template

The visual identity should feel:

LOCAL.
WARM.
CONFIDENT.
HUMAN.
CAPABLE.
PREMIUM WITHOUT BEING PRETENTIOUS.
FEMININE WITHOUT BEING FRILLY.

Think:
Australian local service business + editorial lifestyle brand + premium practical service.

==================================================
2. OVERALL DESIGN PHILOSOPHY
==================================================

Design the site like a real creative agency designed it specifically for this business.

Do not use excessive:
- gradients
- glassmorphism
- floating cards everywhere
- giant rounded containers
- generic abstract blobs
- excessive shadows
- repetitive pill-shaped UI
- excessive icon grids
- artificial 3D illustrations
- AI-looking stock photography
- meaningless decorative shapes
- fake statistics
- fake testimonials
- generic "trusted by thousands" language
- giant gradient hero backgrounds
- repetitive section templates

Avoid making every section look like:

[rounded rectangle]
[icon]
[large heading]
[short generic sentence]

That is typical AI-generated web design.

Instead, create visual rhythm.

Some sections should be spacious.
Some should be image-led.
Some should be typography-led.
Some should use asymmetrical layouts.
Some should use editorial compositions.
Some should use subtle pink accents.
Some should deliberately be very simple.

The page should feel designed, not assembled.

==================================================
3. WEBSITE GOAL
==================================================

The main objective is conversion.

A visitor should understand within approximately five seconds:

1. What Hire A Wifey is.
2. That it provides much more than basic cleaning.
3. That it services Hervey Bay.
4. That the service is trustworthy and professional.
5. That NDIS and DVA clients are welcome.
6. How to book.

The homepage is the primary all-in-one Hervey Bay sales page.

Visitors should be able to:
- understand the service
- see what a Wifey can do
- understand service options
- understand who the service is for
- understand NDIS/DVA support
- check the service area
- understand how it works
- read FAQs
- make a general enquiry
- book
- navigate to the recruitment page

Do not bury the booking CTA.

28. TYPOGRAPHY
==================================================

Use typography to create character.

The logo itself provides the strongest typographic identity.

For body text:
choose a highly readable modern sans-serif.

For selected emotional statements:
use a tasteful editorial serif or expressive display typeface if appropriate.

Do not use:
- five different fonts
- generic futuristic fonts
- overused startup typography
- excessive script fonts

The typography should feel like a premium Australian lifestyle/service brand.

Suggested typographic hierarchy:

H1:
large, confident, editorial

H2:
strong and memorable

H3:
compact and useful

Body:
highly readable, generous line height

Microcopy:
small but clear

Use sentence case and uppercase intentionally rather than making everything uppercase.
